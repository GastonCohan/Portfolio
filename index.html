PROFESSIONAL WORK

Applications I built professionally, shipped to real users.

YPF Ruta

React Native CLI · JavaScript · Node.js View on Google Play

A React Native app for YPF, Argentina's largest energy company, built around a digital wallet for its vehicle fleet. Drivers manage their YPF Ruta cards from their phone — checking balances, starting purchases at service stations and reviewing receipts — instead of relying on the physical card. I contributed to its development at Everis inside a Scrum team, and built and distributed the APK and IPA builds used for internal testing cycles. Over 100,000 downloads.

FotoSprint — Mobile App

React Native · Shopify · JavaScript View on Google Play

A photo printing service built around the phone. People pick shots from their camera roll, turn them into prints and photo books through an in-app editor, and have them delivered at home. It runs across Argentina, Mexico and Chile. I worked on the React Native app as a front-end developer. It holds 4.6 stars across nearly 2,000 reviews and over 100,000 downloads.

FotoSprint — Online Store

React.js · Shopify · JavaScript Visit the store

The e-commerce side of the same service, built on Shopify. Customers browse the print catalogue — photos, photo books, kits, strips, calendars, wall art and magnets — upload their images, configure an order and check out, with the storefront running for both Argentina and Chile. I built front-end features in React on top of the Shopify storefront.

deCampoaCampo

React Native · Redux · Expo · JavaScript View on Google Play

The mobile app for Argentina's largest online cattle market. Producers list their herds from the field and reach thousands of buyers — other producers, meatpackers, supermarkets and butchers. I develop and maintain features in React Native, using Redux for global state and a centralized API service layer behind an API Gateway. I built reusable components on shared architectural conventions, implemented secure token storage with SecureStore so sensitive data never lands in unencrypted storage, and wrote component tests to validate each feature. The app has over 100,000 downloads.

GreenBiz Tracker

React.js · JavaScript Visit the site

A web platform for Green Business certification programs in the United States, now running across eight states. Certified businesses are listed on a searchable map the public can browse by category and distance, and a metrics dashboard aggregates the environmental impact of every certified business — emissions, energy, water and waste saved — with over a billion pounds of CO₂ tracked to date. I built front-end features in React for this U.S. client at Algoritmo Taller Digital, including the interactive map and the data visualisation views.
