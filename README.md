# Portfolio — Gastón Cohan

Personal portfolio site. Live at **https://gastoncohan.github.io/Portfolio/**

React & React Native developer based in Argentina, with 5 years of experience
building production web and mobile applications.

## Stack

Plain HTML, CSS and vanilla JavaScript — no build step. Deployed with GitHub Pages
straight from the `main` branch.

- [Remix Icon](https://remixicon.com/) for icons
- [Poppins](https://fonts.google.com/specimen/Poppins) via Google Fonts

## Structure

```
index.html     Markup and content
style.css      All styles (mobile-first breakpoints at 900px and 600px)
script.js      Smooth scroll navigation and mobile menu toggle
images/        Screenshots and demo videos
cv.pdf         Downloadable CV
```

## Running locally

No dependencies or build required — open `index.html` in a browser, or serve
the folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Deploying

GitHub Pages serves the `main` branch. Pushing to `main` publishes the site.
